# 成长星球原生小程序

V0.0.1 首版客户端，原生 JavaScript / WXML / WXSS，无新增第三方依赖。需求以[审计修订基线](../docs/成长星球_V0.0.1_审计修订基线.md)为准，[实施计划](../docs/superpowers/plans/2026-09-18-miniprogram.md)记录范围，[验证记录](docs/verification.md)区分代码验证与实机验收。

## 已实现

| 页面 | 行为 |
| --- | --- |
| 登录 | 合成开发登录、真实 wx.login 调用入口、一次角色选择；不获取昵称或头像 |
| 首页 | 儿童点餐/任务/学习/成长/我五个入口，家长首页/审批/看板/设置；任务和学习占位，成长仅静态幼苗 |
| 家庭 | 建家庭、邀请码、儿童申请、最小关系分页、自报年龄与独立同意、绑定审批 |
| 档案 | 家长先查有效同意后读写档案；儿童只维护非安全口味偏好 |
| 餐单 | 家长维护当前家庭菜单；儿童按日期/餐次/来源查看、搜索、严格无辣、收藏、过敏提示、选择份数及查看整数分总额 |
| 确认单 | 提报/历史/详情/撤回/重提；家长同意/拒绝/安全餐食建议；E-011 必须二次显式确认 |

| 隐私 | 同意撤回、导出/删除申请、重新核验、工单查询、鉴权导出内容查看 |

## 导入运行

1. 在微信开发者工具导入本目录：`/Users/zhouwei/my-workspace/umbrella/growth-planet-miniapp`。项目配置已指向 `miniprogram/`，默认游客 AppID，不需构建 npm。
2. `miniprogram/config.js` 默认 `http://localhost:8080`、`syntheticLogin=true`、`realDataApproved=false`，与后端 `dev` 合成模式配套。修改 API 地址只改此配置；未实现 `config.local.js` 自动覆盖。
3. 后端需先按[迁移说明](../growth-planet/docs/sprint2-4-migration.md)准备独立的合成开发库，并运行[后端 README](../growth-planet/README.md)中的 `dev` 启动命令。MySQL/Redis/菜单初始数据不会由小程序自动创建，本次未连接或迁移业务库。
4. 本地 HTTP 调试需要在开发者工具项目设置中，由开发者自行选择不校验合法域名。仓库默认 `urlCheck=true`，不自动放宽安全设置。手机上的 localhost 指手机本身，不能直接访问电脑后端。
5. 使用 `parent_demo` 登录并选择家长、创建家庭；另用 `child_demo` 登录并选择儿童，输入邀请码申请。家长记录合成协议同意、批准绑定，再填写合成档案。两者必须独立账号，不允许切换同一账号角色。
6. 家长发放虚拟零花钱并设置额度。由现有运营管理接口准备合成菜品后，家长在餐单页选择日期、餐次和最多50种在售菜品，发布仅对当前家庭有效的菜单；儿童随后可点餐并由家长审批。菜品图片来自后端 `imageUrl`，不以无关食物图片替代实际餐食。

模拟器可先退出登录再登录另一演示账号；多端并行更接近真实审批流程。游客 AppID 不构成真实微信登录验证。

## 开发验证

在本目录执行：

```bash
node --test tests/*.test.js
node scripts/check.mjs
node scripts/check.mjs --native
```

`--native` 默认使用本机微信开发者工具内置编译器，也可设置 `WECHAT_COMPILER_DIR`。只在内存检查编译产物，不写入儿童数据、不上传代码。结构检查验证 JS/JSON、页面注册、本地模块、事件处理器及静态资源引用；不是完整 WXML 语义或布局测试。

开发者工具 CLI 服务端口未开启时，命令行无法打开项目。可直接手动导入，或由开发者在安全设置中开启服务端口后运行：

```bash
/Applications/wechatwebdevtools.app/Contents/MacOS/cli open --project /Users/zhouwei/my-workspace/umbrella/growth-planet-miniapp
```

## 契约与安全

- 统一请求前缀 `/api`；Bearer token；成功响应数字 `code=0`；保留业务错误码、HTTP 状态和 requestId。接口详见[后端补充契约](../growth-planet/docs/sprint2-4-api.md)。
- ID 保持十进制字符串，金额按整数分计算，写入传两位小数字符串。服务器决定最终价格、安全检查、余额和权限，客户端禁用仅是辅助。
- 家长菜品目录使用 `/parent/dish`，菜单读取和发布使用 `/parent/menu-daily`。客户端不发送 `familyId`、`ownerKey` 或 `sourceType`；家庭归属由服务端登录上下文决定。下架或删除引用必须先清理才能再次发布。
- SCHOOL 只读/收藏；未知过敏原、过敏冲突、下架菜品不可提交。家长建议不依赖只读预览中的 `canSelect`，但仍检查过敏安全。
- E-011 预览后再次询问家长，使用完整的最新钱包/额度/确认单版本及结算日期；不自动批准或自动换版本重放。
- 持久化仅保存 token、role、expiresAt。不保存儿童档案、点餐草稿、导出文件或行为日志。隐藏页面时清空敏感表单并停止轮询，旧页面及旧账号响应不回填。
- 网络失败/5xx 的写操作不自动重试。发放、提报及权利申请在本次会话内保留原参数与幂等键，提供原样重试入口。批准/拒绝/建议使用后端已有的单据版本和终态重试规则，不声称这些接口接受幂等键。
- **进程退出、会话过期或退出登录会丢失内存中的待确认请求。** 重新进入后必须核对流水、确认单或工单再操作；当前尚无跨进程恢复账本及权利申请列表接口。此限制是正式上线前待解决项，尤其不能把重新发放当作原请求重试。
- 导出仅在明确确认后鉴权读取并显示 JSON，离开即清空，不提供公开 URL，不自动落盘。当前后端仅支持有限范围，不声称全量导出或实际删除已完成。
- 默认合成配置在体验版和正式版拒绝发请求。切换真实环境必须完成 Q-01/Q-06/Q-07、正式目录/协议、合法域名及隐私配置审核；不能仅修改布尔开关便视为批准上线。
