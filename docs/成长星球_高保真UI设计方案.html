一、功能主题 · 目标用户 · 核心页面 Theme / Users / Pages

🎯 功能主题

产品定位：「成长星球」是一款陪伴 6–12 岁儿童生活自主与学习成长的微信小程序。首期上线模块命名为「小当家·点餐」——孩子浏览学校/家庭当日菜单，向父母确认/提报今日想吃的餐食，无真实支付，仅以「虚拟零花钱」模拟记账，并由家长额度护栏守护。

设计内核：家长护栏优先 · 大字号强图标 · 语音辅助 · 即时正反馈（勋章/动画/成长树）· 隐私合规。

👧 目标用户

① 主角·儿童（11 岁六年级）：能独立图文点按，不擅长长表单；对游戏化、勋章、动画敏感；自我保护意识弱，需家长护栏。

② 监护人·家长：关注安全、消费可控、成长可见；通过审批流与额度完成监护。

③ 运营·后台（Web）：菜单/任务/书单配置、内容审核、风控，不在小程序内。

四、视觉风格总览与落地建议 Visual Language & Handoff

🎨 视觉风格总览

  • 基调：清新、明亮、有安全感；圆角大（16–20px）、留白足、克制阴影。
  • 色彩：儿童蓝主导操作，家长绿守护审批；语义色仅作辅助提示。
  • 图形：强图标 / emoji + 插画，弱化纯文字；卡片化信息组织。
  • 动效：仅 transform/opacity，0.2–0.3s；尊重系统「减少动态效果」。
  • 无障碍：正文 ≥4.5:1、触控 ≥44px、状态图标+文字双编码、语音辅助。

🛠 落地建议（给前端 / 设计）

  • 以本方案 Token 建立小程序 app.wxss 全局变量（颜色/字号/圆角/间距）。
  • 抽离基础组件：菜品卡 / 列表行 / 状态徽标 / 底部 Tab / 金额卡 / 时间线，全端复用。
  • 儿童端与家长端共用组件库，仅换主色变量（--primary）。
  • 状态文案统一走「儿童友好词库」，避免 500/拦截等术语。
  • 配合 P0 的 DDL 与接口状态机（待确认/复核中/已完成/已驳回）落地。
  • 下阶段视觉升级（v1.2 专项，设计评审报告）：毛玻璃导航/分层阴影、SVG 图标库、专业插画（成长树/勋章/空态）、暗色护眼模式、Lottie 弹簧动效；本期先保证可读与落地成本，避免一次改动过大。
