一、背景与目标

当前后端是单模块工程（artifactId growth-planet，共 269 个 Java 文件），C 端（小程序）接口与后台运营端（console）接口、启动类、全部测试混在同一模块。随着运营后台持续扩展，需要拆分为 Maven 多模块结构，达成：

  • 接口层物理隔离：C 端与后台接口分属两个模块，鉴权拦截器各自独立注册，杜绝路径耦合；
  • 接口前缀规范统一（本轮新增决策）：
    • C 端（小程序）：/api/** → /api/mini/**；
    • 运营端：/api/console/** → /api/admin/**；
    • 小程序端、后台前端代码同步调整（见 4.3）；
  • 复用下沉：实体 / Mapper / Service / 公共组件统一沉到 core，两端只依赖不重复；
  • 配置收敛：Spring 基础设施配置类与运行时配置、启动类、运维 SQL 独立成 start 模块，作为唯一可执行入口；
  • 行为变更仅限前缀：除接口前缀及其派生（拦截器路径、测试路径、前端调用路径）外，端口（19100）、业务逻辑、鉴权语义全部保持不变。

  • console 包任何类
  • AdminJwtInterceptor
  • Service / Mapper / Entity
sk-growthplanet-admin

拆分判断口诀：接口（Controller）按端分家 → miniapp / admin；两端共用或被两端 Service 依赖的一切 → core；要"跑起来"的一切（启动类、配置装配、配置文件、SQL、全链路测试）→ start。
config 归属一句话：被 core 编译期引用的属性类（Jwt/Compliance/Notice/Privacy Properties 共 4 个）留 core；其余 Spring 基础设施 @Configuration 全部进 start。

四、依赖关系与关键机制

4.1 依赖声明（唯一方向，禁止反向 / 禁止接口模块互依）

模块依赖说明
coreweb、validation、mybatis-plus-spring-boot4-starter、mysql-connector-j、data-redis、jjwt(api/impl/jackson)、jackson-databind 2.x、lombok；test: starter-test即现 POM 全部依赖；core 保留 web 是因为 GlobalExceptionHandler / RequestContextFilter 需要 servlet API 与 MVC 注解，且依赖会传递给两个接口模块
miniappcoreweb/validation 经 core 传递；仍需显式声明 lombok（optional）——lombok 在 core 是 optional 不会传递
admincore同上
startminiapp、admin传递获得 core；装配 spring-boot-maven-plugin repackage，产出可执行 jar
为什么包名不动、扫描无障碍：四个模块继续共用根包 cn.studykid.growthplanet。启动类 @SpringBootApplication 按其所在包（根包）向下扫描，天然覆盖来自三个模块 jar 内的同根包类；@MapperScan("cn.studykid.growthplanet.mapper")、mapper-locations: classpath*:mapper/*.xml 均无需修改。代价是 Spring 无法在结构上阻止 admin 接口注入 C 端 Service——本改造以"接口层隔离"为目标，此约束靠约定 + Code Review 维护，后续如需强约束再演进为包名分域。

4.2 Web 配置拆分（含前缀平移）

现状拆分 + 前缀改造后
单一 WebMvcConfig（core）注册两个拦截器MiniappWebMvcConfig（miniapp 模块）：JwtInterceptor → /api/mini/**，exclude：/api/mini/auth/wx-login
AdminWebMvcConfig（admin 模块）：AdminJwtInterceptor → /api/admin/**，exclude：/api/admin/auth/login
拦截器改用「限定路径」而非「排除路径」：原 C 端拦截器挂 /** 再排除 console 路径；拆分后两套拦截器仍共存于同一 Spring 上下文，若 C 端继续挂 /** 会拦到运营端 /api/admin/**。因此改为 /api/mini/** 精确限定——原 exclude 中的 /api/console/**、/actuator/**、/error 三项自然失效，无需保留；两套 token 体系（jwt.secret vs jwt.admin-secret）继续物理隔离。

4.3 接口前缀改造明细

4.3.1 C 端：/api → /api/mini（miniapp 模块 15 个控制器）

统一规则：类级 @RequestMapping 的前缀 /api 替换为 /api/mini，方法级路径不动。

类级注解现值目标值涉及控制器
@RequestMapping("/api")/api/miniAuth、Family、Compliance、Menu、Confirm、WishMenu（6 个，方法级路径如 /auth/wx-login、/menu/daily、/parent/**、/child/**、/admin/** 不变）
@RequestMapping("/api/xxx")/api/mini/xxxDev(dev)、Medal(medal)、Wallet(wallet)、CheckIn(child/check-in)、CheckItem(parent/check-item)、FamilyDish(parent/family-dish)、Notice(notices)、Chore(chore)、Schedule(schedule)（9 个）
关键冲突消解：既有 C 端 ADMIN 角色接口（MenuController 的 /admin/dish*、/admin/menu-daily，ComplianceController 的 /admin/compliance/**）目前实际占用 /api/admin/** —— 运营端改用 /api/admin 前会直接撞车。本方案将其随类级前缀一并变为 /api/mini/admin/**：既消除冲突，也让历史上"从 /api/admin 迁到 /api/console"的包袱彻底清零（这批接口本就是小程序端家长-ADMIN 使用，归 mini 前缀语义正确）。

4.3.2 运营端：/api/console → /api/admin（admin 模块）

类现值目标值
AdminAuthController/api/console/auth/api/admin/auth
AdminAccountController/api/console/api/admin
AdminJwtInterceptor（注册路径）/api/console/**/api/admin/**（exclude /api/admin/auth/login）

4.3.3 前端同步调整

前端调整点规模
小程序 growth-planet-miniapp仅 1 处：miniprogram/services/client.js:9 的统一拼接 base + '/api' + path → base + '/api/mini' + path，全部业务请求（services/children.js、operations.js 等的相对路径）自动生效1 行
后台前端 growth-planet-adminsrc/api/console.js 内 12 处 /api/console → /api/admin；可选顺带将文件改名 admin.js（同步 3 个 view 的 import，纯重命名不影响行为）。vite.config.js 代理规则 /api → 19100 无需变化12 处 + 可选改名
小程序测试 tests/*.test.js断言走 mock client 的相对路径（不含 /api 前缀），无需调整；改后跑 69 用例确认0

4.3.4 后端测试路径批量替换（start 模块）

  • C 端 IT（AuthFlowIT、CatalogFlowIT、WantEat*、Wallet* 等 26 个）：字符串 "/api/…" → "/api/mini/…"；
  • AdminConsoleIT：13 用例中 /api/console → /api/admin；
  • 替换完成后全量 IT 回归兜底，防漏改（任何漏改表现为该 IT 整片 404）。

七、测试迁移策略

类别归属理由

BaseIT + 全部 *IT + InfrastructureRegressionTest / LogicDeleteTest / ProductionConfigGuardTest / TransactionRegressionITstart@SpringBootTest 需要启动类；全链路（Controller→Service→真实 MySQL 容器）只有 start 能聚合两端接口；testResources（sql/）与 application-test.yml 同在本模块；测试 URL 前缀随 4.3.4 批量替换
