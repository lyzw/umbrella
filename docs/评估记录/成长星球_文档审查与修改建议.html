U-R-05中 核心页面表 vs 成长屏标注 核心页面表写"成长/任务页 P2（框架）"，成长屏却标注"P4 养成框架，P0 静态幼苗"。P2 / P4 / P0 三套说法并存，阶段口径混乱。 统一为：V0.0.1 仅"静态幼苗"（P0）；任务/成长业务逻辑 P2+；养成动画 P4。表与屏标注一致。 R-02 / R-13
U-R-06中 家长端导航 4 Tab（首页/审批/看板/设置） "家庭看板"屏在"首页"Tab 下展示，且核心页面表把"首页/看板"合并为一项（P0–P2）。"首页"与"看板"既是两 Tab 又内容重叠，职责不清，研发易重复实现或留空。 明确"首页=家庭看板摘要（默认落地页）"，"看板=更细的图表/趋势分析"为独立页；或合并为单 Tab。同步更新核心页面表描述。 R-02
U-R-07中 点餐首页 / 详情页 / 提报页 三级 CTA 首页按钮"告诉爸妈今日菜单"、详情"加入今日菜单"、提报"告诉爸妈"语义层级不清。若首页按钮=直接提交所有❤️，则绕过提报页的份量/备注确认；若只是跳转，文案应改。 明确主流程：home(❤️标记) → detail(加入) → 提报(份量/备注/预览) → 告诉爸妈(submit) → 状态追踪。首页按钮改为"去确认今日菜单 →"跳转提报页，不直达提交。 R-02 / F-016
U-R-08中 筛选 chips / 备注 chips / 营养标签 术语前后不一致：首页筛选"低糖/无辣"，提报备注"少糖/少葱/不要辣"，详情营养标签"无辣/高蛋白/无过敏源"。"低糖"vs"少糖"、"无辣"vs"不要辣"同义不同词。 在设计系统补"标签词库"统一：筛选=低糖/无辣/忌口过滤；备注=少糖/少葱/不要辣/多米饭；营养标签=无辣/高蛋白/无过敏源。 R-15
U-R-09中 点餐首页"无辣"筛选 vs 清炒时蔬"🌶 微辣" 清炒时蔬被标"🌶 微辣"且用红色警示色（t-spicy），但首页又有"无辣"筛选 chip——微辣菜是否被"无辣"过滤不明确；且蔬菜微辣用红色警示色不妥（非风险项）。 定义辣度分级（无/微/中/重辣）；"无辣"筛选仅隐藏中/重辣，微辣保留；中/重辣用警示色，忌口（海鲜/过敏）才用红锁。 R-15 / F-014

6.3 对 UI 稿的逐条修订建议（可直接采纳）

《高保真UI设计方案》建议修订

  1. 额度扣减口径（U-R-01）：提报交互文案改为"提交→待家长确认；额度内自动校验通过、家长一键同意即扣减，超额需显式放行，扣减发生在家长同意后"；预览卡"扣减后余额"→"预计扣减后余额（待爸妈同意）"；审批历史"自动扣减"→"家长同意后扣减"。
  2. 审批示例（U-R-02）：超额复核卡将"油焖大虾×1"换为非忌口超额度组合（如 红烧鸡腿×2=¥24），保证"锁定项不进提交流"，且金额与"单日上限¥20"自洽。
  3. 统一 demo 数值（U-R-03）：初始余额设 ¥50；提报预览"当前¥50 / 预计后¥32"；提交后看板"¥32 / 今日已记¥18 / 待审批0"；三屏数字成时间线。
  4. 额度维度（U-R-04）：设置卡"单日消费上限¥20"配文改为"今日已用 ¥13 / 单日上限 ¥20"（或整卡改"本周额度"配对应上限）。
  5. 阶段标注（U-R-05）：核心页面表与成长屏统一"V0.0.1 静态幼苗 P0；任务/成长业务 P2+；养成动画 P4"。
  6. 家长导航（U-R-06）：明确"首页=看板摘要（默认）"、"看板=趋势分析独立页"，或合并单 Tab；同步核心页面表。
  7. 三级 CTA（U-R-07）：首页按钮改"去确认今日菜单 →"跳转提报页；主流程 home→detail→提报→提交→状态追踪，首页不直达提交。
  8. 标签词库（U-R-08/R-15）：设计系统补统一词库（筛选/备注/营养标签术语一致）。
  9. 辣度与筛选（U-R-09）：定义辣度分级，"无辣"仅过滤中/重辣；中/重辣警示色，忌口红锁。
  10. 登录/绑定（U-G-01）：补 onboarding / 角色路由说明（child 由 parent 微信切换视图）。
  11. 二级监护人（U-G-02）：V0.0.1 不做则置灰/标"即将推出"，关联 Q-01。
  12. 学习 Tab（U-G-03）：V0.0.1 占位"敬请期待"或定义范围阶段。
  13. 三态屏（U-G-04）：补骨架屏、空态、网络错误重试三屏。
  14. 多孩切换（U-G-05）：看板顶部加孩子切换器，或标注 V0.0.1 单孩隐藏。
  15. 营养达标（U-G-06）：PRD 业务规则定义热量/蛋白/蔬菜达标算法，UI 仅展示结果。
  16. 忌口入口（U-G-07）：parent 端或后台补忌口/过敏编辑入口 + 数据流。
  17. 改一改后续（U-G-08）：补替代方案选择/编辑界面或说明。
  18. 零花钱流水（U-G-09）：补流水明细屏（按场景着色）。
  19. TTS 说明（U-G-10）：详情朗读标注 P2 可选 + 依赖（微信同声传译/腾讯云 TTS）。
  20. 后台触点（U-G-11）：补"后台配置→小程序"数据流文字说明。
  21. 触控目标（U-G-12）：份量 ± 由 24px 扩至 ≥44px；或修正声明为"主操作≥44px，列表内微调≥36px"并落地。
  22. 辅助字号（U-G-13）：辅助文字 ≥12px，关键说明 ≥14px。
  23. PRD 映射（U-G-14）：每屏加"对应 PRD：F-xxx"标注，闭合规划→需求→审查。
  24. 低优项（U-G-15~20）：¥ 改虚拟币（R-15）；周图加坐标；warning 与 admin 同色区分；明日切换定义；导出/注销补二次确认弹窗；emoji 辅以文字勿单依赖。
