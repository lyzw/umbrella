## 2. 身份、同意与建档

- 首次角色选择只允许从未选角色到 CHILD 或 PARENT，不允许通过视图切换改写账号角色；选择后换发 token，旧 token 失效。ADMIN 由后台运维配置，不向公开角色接口开放。
- 先建立最小登录/绑定上下文，再由家长针对绑定申请指定的 `childId` 明示同意，审批绑定，最后打开儿童档案表单。无有效同意时不得收集昵称、头像、学校、过敏、口味、行为埋点，也不得在浏览器草稿或日志中保存这些字段。
- 登录/绑定所需的最少账号标识仍可能属于个人信息，不能称为“匿名”。该前置处理的依据、提示及替代监护人先行流程纳入 Q-01 发布闸门；未经确认仅允许不含儿童身份的公开演示。
- `usr_child_profile.family_id` 保持必填；只在 BOUND 且存在有效同意后创建，`profile_status` 为 INCOMPLETE 或 COMPLETE。“待绑定”属于账号/成员关系状态，不再保存为档案状态。
- 家长可读写所绑定儿童档案；儿童只可维护非安全偏好 `dislikes/tastes`。过敏字段仅家长维护，运营不通过普通菜品管理权限编辑儿童档案。
- 同意按 `parentId + childId + consentType + agreementVersion` 留痕，绑定申请必须属于该家庭。撤回与儿童写操作使用相同家庭/儿童授权锁顺序，在事务内读最新同意；撤回提交后新写入返回 E-010，不依赖旧 JWT/缓存放行。在撤回前已经提交的操作保留审计，不自动逆转历史扣减。
- 撤回后取消通知重试中的敏感消息、停用采集与分析，保留家长的权利请求入口。重授同意生成新事件，不覆盖历史。

## 3. 确认单、额度与资金原子性

### 3.1 状态迁移

| 当前状态 | 动作与操作者 | 条件 | 结果及副作用 |
| --- | --- | --- | --- |
| 客户端 DRAFT | 儿童提交 | 已绑定、有效同意、家庭菜单、安全与参数校验通过 | 创建 PENDING；保存价格快照、幂等键和通知事件，不扣款 |
| PENDING | 家长同意 | 最新规则下额度已确认、余额充足、明细版本一致 | 同一事务完成扣款、累计额度、唯一流水、审批记录、COMPLETED 和通知事件 |
| PENDING | 家长拒绝/建议修改 | 相同确认单版本 | REJECTED；保存理由与替代明细，不改原始明细，不扣款 |
| PENDING | 儿童撤回 | 条件状态更新成功 | CANCELLED；记录撤回通知，不扣款 |
| PENDING | 校验失败/余额不足/事务失败 | 任一失败 | 整体回滚，仍为 PENDING；返回明确错误及重试指引 |
| REJECTED/CANCELLED | 儿童改后重提 | 再次执行全部提交校验 | 创建新 PENDING ID，记录 previous_confirm_id；原单只读 |
| COMPLETED | 同意重试 | 同一业务命令 | 返回已完成结果，不再次扣款；其他修改/撤回动作返回409 |

APPROVED 不作为持久化中间状态；“家长同意”与“记账完成”是同一事务的结果。若既有实现已有 APPROVED 数据，须先对账识别已扣款/未扣款记录，再制定迁移，禁止批量直接标为完成。

### 3.2 一致性协议

1. 所有儿童写操作先锁有效家庭/儿童关系，检查同意及权限；审批再依次锁确认单、钱包、额度规则。发放/改规则遵守同一相对锁序。首版采用数据库行锁串行化；钱包 `version` 用于额外条件校验，不宣称这是纯乐观锁方案。
2. 同意接口提交 `expectedVersion`，锁内检查确认单版本与 PENDING。COMPLETED 重试先核对原操作返回原结果；REJECTED/CANCELLED 返回状态冲突。状态成功迁移时 `version + 1`。
3. 以服务端 Asia/Shanghai 当前时间为准，日从00:00开始，周从周一00:00开始。使用独立的 `daily_period DATE` 与 `weekly_period DATE`，在额度规则锁内分别重置累计；仅成功扣款累计，发放不增加消费额度。
4. 审批按最新额度规则重新校验；待审单也受修改后的规则约束。菜单日期不再是当日时拒绝审批，不挪入次日消费。跨日测试须验证拒绝旧菜单及新单计入新周期。
5. 若当前单笔/日/周超限，返回 E-011 和最新额度预览，不扣款。家长确认后提交 `explicitConfirm=true` 及预览的 `walletVersion/ruleVersion/confirmVersion/usageDate`；锁内重核，预览过期仍返回 E-011，不能用陈旧的布尔授权放行。
6. 条件更新钱包须同时满足余额足够、版本一致、状态正常，检查影响行数；流水使用 `(wallet_id, scene, ref_id, trans_type)` 唯一约束，确认扣款 `ref_id` 必填。流水、额度、状态、审批与站内通知事件任何一步失败均回滚。
7. 提交和发放使用 `Idempotency-Key`，范围为登录操作者、操作类型与请求键；保存规范化请求摘要。同键同参返回原结果，同键不同参返回 E-012。键不得因软删除而复用；客户端超时以同键重试，不盲建新单。
8. 首版不自动冲正或退回已完成虚拟消费；异常由对账与受审计的人工处理流程处理。审计日志记 requestId、actorId、childId、confirmId、规则版本、余额前后、事务结果和错误码，禁止明文儿童档案。

Sprint 1查询补充（阶段记录）：关系状态查询保留最小关联，家长可发现待审批childId/applyId，儿童可恢复申请进度；撤回后仍可查关系，但档案/偏好读取和写入均返回409/E-010。偏好操作缺少COMPLETE档案时409/E-002，采集闸门关闭403。儿童按绑定家庭创建家长的当前有效同意授权，家长账号/关系无效时403；同意须匹配申请版本且未过期。该阶段未改数据库结构，F-022收藏持久化当时未实现，现已纳入Sprint 3后端并通过隔离回归。接口完整入参/出参见[后端README](../growth-planet/README.md)及[Sprint 2–4 API补充](../growth-planet/docs/sprint2-4-api.md)。

账号安全：首版访问token有效30分钟，不做长期refresh token；过期重新wx-login，服务端重新加载账号状态和权限，退出/禁用使会话失效。ADMIN预置绑定受控账号，无公开注册/升级角色接口；后台授权和日志须经安全评审。

提交与审批均校验：来源FAMILY、菜单日期为当日、PUBLISHED、菜品属于该菜单且ON_SALE、数量范围、过敏信息已声明且不命中儿童过敏编码。UNKNOWN只展示“信息待确认”，不能提交或审批；偏好不喜欢只提示，不作为安全阻断。审批使用提交时单价快照，不静默重新定价；建议修改/重提按当前菜单重新取价。

## 6. 通知、隐私与非功能

- 家长在自身绑定完成/审批/设置界面申请审批提醒授权；儿童只能申请自己的完成通知，不能为另一账号授予订阅权限。授权被拒不阻断业务，站内通知仍可查询。
- 业务事务内写站内记录和订阅待发事件，提交后任务扫描发送；按1分钟、5分钟、30分钟重试，最多3次重试，失败进入人工排查。订阅状态为PENDING/SENT/FAILED/UNAUTHORIZED；SENT仅表示平台受理，不表示送达/已读。避免在超时后声称外部通道严格仅发一次。
- 首版导出/删除支持工单人工处理：1个工作日确认受理、15个工作日内处理或说明延期原因，均为产品服务目标而非法律期限；上线前确认人员、验证身份、审批与操作记录。删除覆盖主库、缓存、索引和导出文件；恢复备份后重放删除记录，防止数据复活。
- 数据保留提案：技术错误日志30日、行为分析原始记录30日、通知90日、备份滚动30日、导出文件24h；账号档案在撤回后停止处理并进入权利请求流程；同意、审批、虚拟流水与安全审计保留期限须由合规按适用义务确认。未确定的类别禁止以“长期/永久”默认上线，保留配置及清理演练是发布闸门。
- 营养首版只展示有来源的每份热量和成分，无来源显示“暂无数据”，不计算“达标”、不展示“无过敏源”。“无辣”严格spiceLevel=0；微辣、中辣、重辣均排除。
- 性能验收提案：100并发、1000家庭、每家庭100确认单数据，持续15分钟；同地域预发布4核8GB应用节点，数据库独立4核8GB，无外部微信耗时计入API统计。常规API P95≤300ms、5xx<1%；第三方耗时单独记录。移动端固定iOS/Android各一台并登记型号、微信和基础库版本，10Mbps/RTT100ms下各30次冷启动，骨架出现P95≤1s、首屏可操作P95≤2s；不足以通过则调整设计并重新审批指标。
- 通知指标：每24h业务已提交事件中，5秒内可查询站内记录的比例≥99%；订阅平台受理率按已授权有效请求单独统计，不把未读算失败、不把入库算触达。家长实际审批时间仅观测分布，不承诺人类异步操作的固定响应时间。
- 可访问性：正文项目目标4.5:1；蓝色白字改#1d4ed8、绿色白字改#15803d；所有可操作目标≥44×44px为项目设计标准。原型不等同完整WCAG认证，需实机读屏、焦点和减少动态效果验证。
- 夜间限制/时长限制是待评审产品策略，不宣称统一法定义务。22:00–08:00仅候选默认，适用儿童侧、Asia/Shanghai；家长管理和权利请求不被锁定。具体时长、覆盖例外和法规适用由产品/合规确认后配置。
