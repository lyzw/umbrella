「成长星球」· V0.0.2 UI+UX 设计稿（P2 生活自主）

面向 V0.0.1（9 页 · 点餐 MVP）增量设计的 P2 生活自主模块：零花钱看板、家务、健康打卡、日程、购物、奖励兑换、二级监护人、勋章墙。覆盖 UI 视觉规范 + UX 信息架构 + 交互流程 + 三态 + 无障碍，组件与页面均按现状类名落地，便于前端直接复用。

沿用 V0.0.1 tokens扩展分类语义色儿童 ≥44px 触控WCAG 2.2 AA高保真可落地

一、设计原则

  1. 角色化双色：儿童端蓝、家长端绿，沿用 V0.0.1 .parent 覆盖机制；V0.0.2 新增功能沿用宿主页角色色，不引入第三主色。
  2. 虚拟属性明示：所有金额/余额统一标注"虚拟单位"，不出现"支付/充值/提现"等真实交易词汇（合规 + G2 零真实支付）。
  3. 赚→花→管可视化：用进度环/条即时反馈额度与连续天数；奖励用勋章给予正反馈，淡化"减法"焦虑。
  4. 儿童友好 + 家长护栏：大点击区、图标+文字双编码、状态显式；敏感操作（购物/兑换/委托）必须家长确认或复核中态。
  5. 连续而不打断：动效仅 transform/opacity，支持减弱动效；加载/空/错三态统一，避免白屏与硬报错。

六、核心交互流程（UX 状态机）

6.1 家务：认领 → 完成 → 确认 → 入账

stateDiagram-v2 [*] --> CLAIMED: 儿童认领 CLAIMED --> SUBMITTED: 标记完成 SUBMITTED --> CONFIRMED: 家长确认(同事务发奖励) SUBMITTED --> REJECTED: 家长驳回 CONFIRMED --> [*] REJECTED --> [*] note right of CONFIRMED 发虚拟币 + 勋章 + 流水(REWARD_ADD) 失败整体回滚保持 SUBMITTED end note

6.2 购物 / 兑换：跨场景额度护栏

flowchart TD A[儿童提交购物/兑换] --> B{余额≥消耗?} B -- 否 --> C[拦截:虚拟不足] B -- 是 --> D{累计支出+本单≤周额度?} D -- 是 --> E[审批/兑换通过 扣减+流水] D -- 否 --> F[状态=复核中 需家长放行] F --> G{家长放行?} G -- 是 --> E G -- 否 --> H[拒绝 不扣减] E --> I[通知儿童]
关键 UX 点：奖励发放（REWARD_ADD / MANUAL_GRANT）为"收入"，不触发上述额度判定；只有消费类（CONSUME_DEDUCT / EXCHANGE_DEDUCT）参与。避免"赚钱反而超额"的困惑（F-041 / A-01）。

6.3 二级监护人：邀请 → 授权 → 受限操作 → 到期降级

flowchart LR P[家长邀请] --> Q[对方接受] --> R[家长确认范围] R --> S[生效:仅可审批点餐/家务/购物] S --> T{到期或撤销?} T -- 到期 --> U[自动降级 通知] T -- 撤销 --> U S -. 越权操作 .-> V[返回 403 不可见]

七、三态规范（空 / 加载 / 错误）

状态触发UI 表现文案原则操作
空态 empty无数据（首用/筛选无果）居中图标 + 一句引导，配色柔和，不报错正向激励（"发布第一个家务吧🌱"）提供"去添加"主按钮
加载态 loading请求中（首屏/翻页/提交）骨架屏或 spinner，按钮 disabled 防重复不出现白屏；金额类显示占位禁用重复提交
错误态 error网络/服务/校验失败红边提示 + 原因 + 重试；不弹系统框儿童可读（"网络开小差了"）"点击重试"按钮
复核中/受限超额度/委托人越权黄色警示徽章 / 403 友好提示说明"等爸妈确认"或"无权限"家长端放行 / 引导联系家长

八、无障碍与适配

  • 触控：所有可点元素 ≥44px（按钮 46 / 图标 44），沿用现状；列表行高 ≥48px。
  • 对比度：正文墨色 #172033 on #fff 对比 ≥7:1；徽章文字用深底深字（如 #154a9e on #edf5ff），满足 WCAG 2.2 AA。
  • 双编码：状态不只靠颜色——图标+文字+形状（如"复核中"用 🟡 徽章+文字，不止黄色）。
  • 动效：仅 transform/opacity，且 @media (prefers-reduced-motion: reduce) 全部关闭（已存于现状 app.wxss）。
  • 焦点：键盘/指针聚焦有可见 outline（现状已加）；小程序内等价用聚焦态样式。
  • 隐私：健康打卡在监护人同意范围内采集；撤回后入口置灰并提示（呼应 F-033/NF-5/A-03）。
  • 包体：图表用轻量 SVG/CSS 实现，图标走 SVG sprite，控制新增资源体积（继承 NF-2）。
